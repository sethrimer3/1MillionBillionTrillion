# million. billion. trillion.

An installable mobile idle game built with HTML, TypeScript, CSS, original Paint-style sprites, and Pixelify Sans throughout. A dark, torchlit gate connects seven rainbow worlds and two prestige crystal worlds. The interface has no tutorial screens or walkthroughs.

## Development

Node.js 22.18+ or 24+.

```sh
npm ci
npm run dev
```

```sh
npm test              # progression, upgrades, save migration, offline production
npm run build         # type checking, production bundle, offline service worker
npm run preview       # serve the production app
npm run test:browser  # desktop/mobile gameplay, navigation, save recovery, offline relaunch
```

Browser tests use system Chromium when available. Otherwise, run `npx playwright install chromium`, or set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` to a Chromium executable. The browser test runner builds and starts its own production server.

## Files

- `src/main.ts`: application navigation, activities, settings, and UI feedback.
- `src/game.ts`: progression, purchases, save migration, and discoveries.
- `src/rpg.ts`: saved maze exploration, automatic party combat, abilities, recruitment, equipment, and quests.
- `src/rpg-map.ts`: the connected maze, radial area difficulty, and route finding.
- `src/rpg-data.ts`: regions, equipment, companion definitions, and quests.
- `src/rpg-view.ts`: the yellow world's battles, inventory, map, and character views.
- `src/rpg.css`: illustrated RPG scenery and in-game panels.
- `src/arena.ts`: green-world ship movement, polygon collisions, weapons, merging, linear upgrades, and offline crystal payouts.
- `src/arena-view.ts` and `src/arena.css`: canvas arena, fleet dock, and responsive controls.
- `src/prestige.css`: permanent upgrade tree, crystal caves, and prestige UI.
- `src/scene.css`: full-screen scene composition, in-scene navigation, and compact secondary screens.
- `src/pixel.css`: pixel typography sizing, crystal badges, and illustrated scene props.
- `src/ui-art.css`: sprite icons, hand-drawn frame borders, and settings toggles.
- `src/art.ts`: sprite presentation and environmental artwork.
- `src/style.css`: app layout, world scenery, and sprite animations.
- `public/sprites/`: original hand-drawn RPG doodles and raster artwork, including three-frame flame animations.
- `scripts/draw_scene_sprites.py`: original drawn scenery including mountains, fences, pots, reeds, and lanterns; Python 3, no packages needed.
- `scripts/draw_ui_sprites.py`: original transparent bitmap icons, seven distinct rainbow crystal silhouettes and their unfilled sockets, frame corners, and toggles; Python 3, no packages needed.
- `scripts/draw_sprites.py`: reproducible sprite sources; run with Python 3, no packages needed.
- `scripts/draw_rpg_sprites.py`: reproducible RPG characters, enemies, props, and equipment; Python 3, no packages needed.
- `scripts/draw_kingdom_sprites.py`: original maze tiles, biome scenery, four companion portraits, and ability icons; Python 3, no packages needed.
- `scripts/draw_crystal_sprites.py`: reproducible iridescent/void crystals and prestige doodles; Python 3, no packages needed.
- `scripts/draw_arena_sprites.py`: original ship hulls, faceted crystals, mines, weeds, and drawn control frames; Python 3, no packages needed.
- `vite.config.ts`: production asset caching and service-worker generation.

Existing `mbt-save-v1` saves migrate in place. Progress remains local to the browser; export/import is available in Settings. Assets and fonts are bundled locally. The production app works offline after its first completed load; processes and offline caches are independent of gameplay saves.

The GitHub Pages workflow tests, builds, and deploys `dist/`. Configure Pages to use GitHub Actions. Relative asset URLs, manifest scope, and service-worker registration support the repository's Pages subdirectory.

Prestige uses a persistent, three-branch upgrade tree. The first reset awakens the iridescent eighth world; the third awakens the void ninth world. Run scores, pocket upgrades, and RPG progress restart; tree purchases, relics, and preferences remain. Existing eight-world saves retain their progress, including an already discovered secret world.

Gate targets are exact products: `10^27`, `10^30`, `10^32`, `42 × 10^32`, `42 × 10^47`, then `42 × 10^65`. Further prestiges multiply the final target by 1,000 each time. All available world scores multiply, even when a permanent crystal is awake before the other rainbow worlds.

The gate is a full-viewport scene with navigation in its top-left corner. Its seven crystal-shaped recesses align with individual arch stones; unlocked crystals are direct game entrances. Game navigation stays in the scene while secondary views scroll inside the viewport. The arch source and the socket positions are defined together by `scripts/draw_sprites.py` and `src/scene.css`; recess artwork is generated by `scripts/draw_ui_sprites.py`. The masonry and wooden door leaves are separate sprite layers, keeping the crystals fixed when the gate opens.

The green world, Shard Drift, runs an idle fleet of forward-moving triangle ships. Crystal breaks award spendable coins and lifetime shards for the gate multiplier; hits alone award nothing. Two matching hulls merge into the next hull, unlocking a gun, minelayer, continuous beam, rotating spiral, and weakest-crystal seeker. Ship prices, damage/speed/capacity upgrades, stage health, and payouts use arithmetic growth. The mobile fleet dock becomes a side panel on wide screens. Physics runs at 60 steps per second, with smaller steps for fast ships; long absences use estimated fleet damage and an arithmetic stage calculation to award completed crystal breaks without simulating hours of frames. Existing green scores and upgrades migrate, with previous upgrades contributing to collision and weapon damage. Prestige resets the fleet while permanent speed and yield bonuses carry into subsequent runs.

The yellow world's Pocket Kingdoms atlas has 81 rooms connected by a branching maze. Clicking a floor square queues a route; the party walks it one square at a time, stopping at uncleared encounters. Distance from the central camp increases enemy health, attack, group size, and rewards. Cleared areas can be revisited for automatic battles. The adventurer can recruit four different companions and take three along, making a party of four. Each member has individual health, mana, and an action clock; changing their selected ability affects the next action without resetting its timer. Rangers mark targets or fire volleys, guardians shield or provoke, mages cast or restore mana, and healers mend the weakest ally or heal the party. A fallen adventurer can be carried by surviving allies, and camp revives everyone after defeat. The map, queued route, member health, chosen abilities, and encounter survive saves and offline play. Older RPG saves keep earned levels, inventory, currency, companions, and quests and begin at the new central camp. Equipment, forging, attributes, renown upgrades, and prestige remain available; clearing the outer regions opens harder atlas pages.
